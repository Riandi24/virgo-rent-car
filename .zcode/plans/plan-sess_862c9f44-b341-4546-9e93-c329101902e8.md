# Fitur: Galeri Foto Multi + Detail Mobil di Halaman Armada

## Tujuan
Pelanggan bisa klik gambar mobil di `armada.php` → muncul modal "detail mobil" berisi galeri foto (eksterior/interior, lebih dari 1 foto) + review mobil tersebut, sebelum klik "Pesan Sekarang". Admin bisa upload/hapus beberapa foto per mobil.

## 1. Database — tabel baru `tbl_kendaraan_foto`
Struktur meniru `tbl_review_foto` yang sudah terbukti:
```sql
CREATE TABLE tbl_kendaraan_foto (
  id_foto INT AUTO_INCREMENT PRIMARY KEY,
  id_kendaraan INT NOT NULL,
  foto_path VARCHAR(255) NOT NULL,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (id_foto...) FOREIGN KEY (id_kendaraan) REFERENCES tbl_kendaraan(id_kendaraan) ON DELETE CASCADE
) ENGINE=InnoDB;
```
Ditambahkan ke `db_virgo_rent.sql` dan dijalankan ke database live. Kolom `gambar` lama tetap dipakai sebagai foto utama/thumbnail.

## 2. Admin — `admin/kelola_mobil.php`
- Tambah input `foto_tambahan[]` (multiple, max 5) pada form tambah/edit, pola validasi & penyimpanan persis seperti upload review: whitelist ekstensi `jpg/jpeg/png/webp`, nama file `mobil_<time>_<i>_<hex>.<ext>`, simpan di folder `uploads/mobil/` (dibuat otomatis).
- Insert satu baris per foto ke `tbl_kendaraan_foto` (prepared statement).
- Saat edit: tampilkan daftar foto tambahan yang sudah ada, masing-masing dengan tombol hapus (hapus file + baris DB).
- Saat hapus mobil: baris foto ikut ter-CASCADE; tambahkan unlink file foto tambahan sebelum DELETE.

## 3. Halaman `armada.php` — modal detail + galeri
- Query join: foto tambahan difetch ke map `$mobil_foto[id_kendaraan][]`, review (status Approved) ke `$mobil_review[id_kendaraan][]` beserta rata-rata rating.
- Gambar di kartu mobil jadi bisa diklik (cursor pointer + hint "Lihat detail"). Klik membuka modal detail:
  - **Galeri foto**: foto utama besar + thumbnail, navigasi prev/next/keyboard/Esc — JS diadaptasi dari lightbox `#reviewImageModal` di `ulasan.php`.
  - **Info mobil**: nama, kategori, transmisi, bahan bakar, kursi, harga, status.
  - **Review card**: 2–3 review teratas (nama, bintang rating, komentar, foto review jika ada) + rata-rata rating.
  - Tombol "Pesan Sekarang" (link ke `pemesanan.php?mobil=...` seperti kartu, tetap bawa parameter wisata), nonaktif jika status ≠ Tersedia.
- Data galeri & review per mobil dikirim ke JS via atribut `data-*` berisi JSON (pola sama seperti `data-gallery` di ulasan.php) — tanpa fetch/AJAX tambahan.

## 4. CSS — `css/style.css`
Tambah class kecil untuk modal detail (thumbnail aktif, badge jumlah foto di kartu misal "5 foto") bergaya glassmorphism yang sudah ada.

## 5. Verifikasi
- `php -l` semua file yang diubah.
- Jalankan SQL pembuatan tabel, tes upload via curl (simulasi POST multi-file) dan pastikan file tersimpan + baris DB terbuat.
- Cek `armada.php` via localhost: kartu tampil, modal terbuka saat klik gambar (uji browser), tidak ada PHP warning/notice.
